# 九九・かけ算文章題・漢字を学べるモンスターたいじゲーム

小学2年生の自由研究用に作った、ブラウザで遊べる学習ゲームです。
モンスターが出てくるので、九九・かけ算の文章題・漢字の問題に正解して倒していきます。

## 遊び方（今できること）

1. `index.html` を開く（下記「確認方法」参照）
2. タイトル画面で「はじめる」を押す
3. モード選択画面で「九九モード」を選ぶ（今遊べるのはここだけ）
4. モンスターが出てくるので、九九の問題に正解して倒す
5. 5体のモンスターを全部倒すとクリア！

「文章題モード」「漢字モード」は、まだ準備中です（今後、詳しい仕様と問題データを追加して遊べるようにします）。

## 動作環境

- iPad の Safari
- PC の Chrome

ビルドツールやインストール作業は不要です。素のHTML/CSS/JavaScriptだけで動きます。

## ローカルで確認する方法

**方法A: ファイルを直接開く**
`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップして開く。

**方法B: 簡易サーバーを立てる（推奨）**
```bash
cd taichi-study-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## ディレクトリ構成

```
taichi-study-game/
├── index.html            # ゲーム本体
├── css/style.css         # スタイル
├── js/
│   ├── main.js            # 画面切り替え・イベント処理
│   ├── battle.js          # バトルのロジック
│   ├── storage.js         # ベストスコアの保存
│   └── data/
│       ├── kuku.js         # 九九の問題（実装済み）
│       ├── mondai.js       # 文章題の問題（準備中）
│       ├── kanji.js        # 漢字の問題（準備中）
│       └── monsters.js     # モンスターの一覧
└── assets/
    ├── images/monsters/    # 敵キャラ画像を入れる場所
    └── images/ui/          # アイコンなど
```

開発ルールの詳細は [`CLAUDE.md`](./CLAUDE.md) を参照してください。
