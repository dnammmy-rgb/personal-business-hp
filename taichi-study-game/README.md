# 九九・かけ算文章題・漢字を学べるモンスターたいじゲーム

小学2年生の自由研究用に作った、ブラウザで遊べる学習ゲームです。
モンスターが出てくるので、九九・かけ算の文章題・漢字の問題に正解して倒していきます。

## 遊び方

1. `index.html` を開く（下記「確認方法」参照）
2. タイトル画面で「はじめる」を押す
3. モード選択画面で「かけ算モード」か「漢字モード」を選ぶ（敵は共通の8体）
4. モンスターが出てくるので問題に答える
   - 九九の計算問題（例：`7 × 8 ＝ ？`）は答えを数字で入力して「こたえる」
   - かけ算の文章題は、正しい式を3つの中から選ぶ（例：`4×3` / `3×4` / `5×3`）
   - 漢字モードは、ひらがなの読み方に合う漢字を3つの中から選ぶ（例：「くも」→ `雪` / `雲` / `風`）。中ボス・ラスボスになると、反対語（「東の反対は？」）・なかま探し・季節や曜日の並び（「春・夏・秋・○」）なども混ざる
   - **敵が強くなるほど、九九は6〜9の段や難しい組み合わせが増え、漢字は2年生レベルの語や応用問題が増える**（ザコ敵はやさしめ、中ボス・ラスボスは少しずつ難しく）
   - 正解すると「せいかい！」→（文章題のときは使った式と答えを一瞬表示）→「キック！」（漢字モードは「ブレイクキック！」）でモンスターを攻撃
   - **3問連続で正解すると必殺技「怒りの拳」が発動！** ザコ敵は一撃で撃破、中ボス・ラスボスにはHPを半分けずる大ダメージ。まちがえると連続記録はリセットされる
5. ザコ敵（こだこ→小ジャケ→タツノオトシゴ→鮭）→中ボス（青鬼→赤鬼→黒鬼）→ラスボス（？？？）の8体を順番に倒すとクリア！
   - ザコ敵・中ボス・ラスボスでBGMが自動的に切り替わります（中ボス・ラスボスは低音の効いた重い曲調に）
   - ラスボスは戦闘中は「？？？」のまま。倒すと「大魔王 闇をたおした！」で正体が判明する

画面右上の🔊ボタンで効果音・BGMのオン/オフをまとめて切り替えられます。

## 動作環境

- iPad の Safari
- PC の Chrome

ビルドツールやインストール作業は不要です。素のHTML/CSS/JavaScriptだけで動きます。効果音も外部ファイルを使わずWeb Audio APIでその場で鳴らしているので、追加の音声ファイルは不要です。

## ローカルで確認する方法

**方法A: ファイルを直接開く**
`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップして開く。

**方法B: 簡易サーバーを立てる（推奨）**
```bash
cd taichi-study-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## ディレクトリ構成

```
taichi-study-game/
├── index.html            # ゲーム本体
├── css/style.css         # スタイル
├── js/
│   ├── main.js                 # 画面切り替え・イベント処理・演出
│   ├── battle.js                # バトルのロジック（必殺技の判定もここ）
│   ├── multiplicationMode.js    # 九九と文章題をまぜて出題する
│   ├── kanjiMode.js             # 漢字の3択を出題する
│   ├── storage.js               # ベストスコアの保存
│   ├── sound.js                 # 効果音（Web Audio APIでその場合成）
│   └── data/
│       ├── kuku.js                     # 九九の問題（敵の強さで段の傾向が変わる）
│       ├── multiplicationQuestions.js  # かけ算の文章題（実装済み）
│       ├── kanji.js                    # 漢字の問題（実装済み・1〜2年生56語＋反対語・並び順など）
│       └── monsters.js                 # モンスターの一覧
└── assets/
    ├── images/monsters/    # 敵キャラ画像（8体分の透過PNG）
    └── images/ui/          # アイコンなど
```

開発ルールの詳細は [`CLAUDE.md`](./CLAUDE.md) を参照してください。
